# TXT to Excel Converter

A free, fast, and browser-based TXT to Excel converter built using HTML, CSS, and JavaScript.

Convert plain text files into Excel (.xlsx) and CSV (.csv) formats without requiring any backend or server.

## Features

- TXT File Upload
- Drag & Drop File Upload
- TXT to Excel (.xlsx) Conversion
- TXT to CSV Conversion
- Automatic Delimiter Detection
- Tab, Comma, Pipe, and Semicolon Support
- Data Preview Table
- Positive Transaction Amount Formatting
- Automatic Transaction Amount Total
- Excel Number Formatting (0.00)
- Preserve Original Transaction Order
- Large File Processing Support
- Responsive Design
- Client-Side File Processing

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- SheetJS (xlsx)
- Tailwind Css Modern 

## Privacy

All file processing happens locally in your browser. Your uploaded TXT files are not sent to any external server.

## Installation

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser or use VS Code Live Server.
